# go-cli

**go-cli** is a core package designed to generate and scaffold CLI templates. Users can easily download this package and run the `generate` command to set up their own custom CLI applications.

## Features

- Scaffold a new CLI project quickly
- Customizable templates
- Simple `generate` command to bootstrap your CLI

## Getting Started

1. **Download the package:**
    ```sh
    go install github.com/pleone55/cli-core/cmd/generate@1.0.0
    ```

2. **Run the generate command:**
    ```sh
    generate myclie
    ```

3. **Follow the prompts to customize your CLI.**

## Usage

After running the `generate` command, your new CLI project will be scaffolded in the specified directory. You can then start building your custom commands and logic.
